How to use this app

  1. Work in order. Use the pill bar for sections, the Prev/Next buttons, or the page menu at the bottom. The Table of Contents cards are tappable.
  2. Type anywhere. Every line, box, checkbox and score is editable at any time. Your answers save automatically in this browser.
  3. Take the quiz first. The score, profile and recommended worksheets calculate for you. Lock your Day-1 score, then retake on Day 30.
  4. Use the calculators. Cash Flow, Profit-First Split, Emergency Buffer, Debt Detangler and Decision Matrix do the arithmetic live.
  5. Edit and undo. Each page has Clear this page (with Undo). Tools → Load sample data shows a filled example; Clear sample data removes only the sample.
  6. PDF reporting. Tools → Build PDF report. Choose sections, then Print / Save as PDF or Download PDF file. You can also print the whole workbook, filled or blank.
  7. Back up. Export a .json backup to move your work to another device, and Import it there.
